How It Works

Multi-Stage
Detection Engine

1

HSV Flame Masking

Color space analysis targeting bright visible flames

  • Analyzes RGB → HSV color space
  • Detects high-saturation warm colors
  • Filters false positives in real-time
2

YCrCb Ember Detection

Warm chrominance analysis for low-light conditions

  • Processes YCrCb chrominance channels
  • Catches indirect glow & embers
  • Optimized for night/low-light scenes
3

Smoke Identification

Low-saturation region analysis with brightness exclusion

  • Analyzes gray/low-sat regions
  • Brightness-based filtering
  • Minimizes environmental noise

REST API Endpoints

POST
/detect
Upload an image for fire/smoke detection. Returns bounding boxes, confidence scores, and class labels.
curl -X POST https://api.fireguard.ai/v1/detect \ -H "Authorization: Bearer YOUR_API_KEY" \ -F "file=@fire_image.jpg"
POST
/detect_frame
Process individual video frames for real-time detection. Optimized for streaming.
curl -X POST https://api.fireguard.ai/v1/detect_frame \ -H "Content-Type: application/json" \ -d '{"frame": "base64_encoded_image"}'
POST
/process_video
Submit a video file for batch processing. Returns job ID for status tracking.
curl -X POST https://api.fireguard.ai/v1/process_video \ -F "file=@fire_video.mp4" \ -F "webhook_url=https://yourserver.com/callback"
GET
/video_progress/:id
Check processing status of a submitted video job.
GET
/health
System status check. Returns uptime, model version, and API health.
